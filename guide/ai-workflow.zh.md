# 学习、复习与分享

从一个小问题开始就可以。今天写下 quicksort 的含义，明天补上代码，再把易错点和练习加进去；笔记不必一次成型。

## 整理正在学习的内容

一篇 Note 可以对应一门课、一次 Quiz 或一个主题。里面的 Section 是独立的知识节点，可以单独查找、复习、移动，也可以在别的笔记中引用。相关内容放在同一个 Section；需要分开时，再拆成多个 Section 或 Note。

使用标题、列表、表格、代码、公式和图片来表达内容。代码保留缩进，公式使用数学格式，图片和来源放在用到它们的位置。某道题里只出现一次的技巧，写成题内的解释即可，不必为它新建标签。

如果先在 Google 文档中积累内容，保留每个小节的标题和边界。整理时分别准备笔记正文与练习文件，先检查公式、代码、图片和答案，再导入。当前不会自动同步 Google 文档。

## 把笔记变成可以练习的问题

- **正反面卡片**：正面写问题，背面放答案和解释。先尝试回忆，再揭示答案。
- **选择题**：保留完整选项、正确答案和解释。
- **填空与隐藏片段**：隐藏需要回忆的部分，保留足够上下文。
- **已有的数学题**：题目就是正面，解法和题内笔记放在背面。

在 Practice 中使用 Copy Prompt 准备问题，在 Import JSON 中导入已经核对过的练习。导入格式是 `nodal.practice.v1`；同一张卡片持续更新时保留它的 ID，这样现有复习进度不会被当成新卡重置。

创建或导入 Practice 不会开始安排复习。准备好学习时，点击 **Start learning** 开启一道题，或用 **Start learning & review** 开启选中的题。仅查看或揭晓答案不会保存成绩。

读笔记、看答案与完成一次 Review 是不同的动作。Review 中选择 Forgot、Partial 或 Recalled 后，才会更新该练习的记忆状态和下次复习时间。Section 的手动掌握度是另一种自我标记，不会代替题目的复习安排。

## 具体的复习时间

复习安排保留具体日期和时间，不只是“今天”。正常复习队列在到期时间之后才显示该题；从 Practice 手动选择时，也可以提前练习。

开启 Research recording 后，记录会保留题目展示时的应复习时间、实际展示时间和时间差。时间差为正表示晚于安排，为负表示提前练习。尚未完成的尝试与已经评分的 Review 分开记录，不把退出或没来复习自动判成 Forgot。

## Events：需要记住的日期

Events 可以是竞赛、考试或每周的 Quiz。支持单次日期和每周循环，可关联多篇笔记，并按下一次日期排序。

在 Events 中选择 New event，填写名称、日期或星期，再勾选关联笔记。Show on Today 控制首页是否显示；Show days remaining 控制是否显示剩余天数。循环事件会显示 Every Wednesday 等星期提示。

Events 是日期提醒。题目的复习计划仍单独设置，关联活动不会自动改变每张卡片的复习节奏。

## 保存与恢复

Data & backup 中的 Export full backup 会准备一个 ZIP，包含笔记、标签、地图、图片、练习、当前复习状态、复习历史、计划、Events，以及已经开启采集的研究记录。下载后确认文件已保存，并保留在自己能够管理的位置。

正常备份始终保留成绩和复习安排，不会清空进度。

Restore from backup 会替换当前工作区的内容和复习状态。已经保存的研究档案会合并保留，并记录恢复操作。整理内容或恢复旧备份之前，先导出当前版本。


## 研究记录

Research recording 是可开启或停止的独立记录区。它保存题目展示、答案揭示、选择、已完成评分、内容修改和部分安排背景，并随完整备份导出。关闭采集不会删除已有档案。

记录从开启时开始；此前没有采集过的经历无法补回。自评表示自己记得多少，不等于独立验证的正确率。应用之外的学习和没有打开网站时的原因，也不会自动知道。

## 分享学习进度

完整备份中同时提供一份独立的公开学习快照，包含当前笔记、地图、活动日期和每道题的复习进度。它不包含原始作答、研究事件或恢复档案。

使用这份快照更新网站后，Study progress 会显示已发布的内容和更新时间。访问者看到的是这次发布的学习状态，自己的笔记和复习数据保持独立。继续学习后，再导出一份新的备份更新即可。

目前这是按次发布，不是实时云同步。GitHub Pages、不同本地地址和不同浏览器各有自己的工作数据；更新网站代码不会自动上传浏览器中的学习记录。
