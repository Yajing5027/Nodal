# Nodal

**写下来，看见联系，再练到真正能想起来。**

[English](README.md) · [简体中文](README.zh-CN.md) · [打开 Nodal](https://yajing5027.github.io/Nodal/)

有些知识，看笔记时觉得认识，考试时却讲不清、做不出，过一周又想不起来。Nodal 把通常散落在不同地方的学习过程放进同一个空间：笔记、知识之间的联系，以及用来检验记忆的问题。

你可以先写一篇笔记，再把它整理成小节、放进知识地图、从中制作回忆题，并在之后反复练习。同一段解释不必为了地图、卡片和复习计划抄写好几遍。

比如学完树和堆，你可以先写一篇笔记，把 Java 实现单独放在一个小节里，在地图上连接堆操作与相关概念，再给数组索引写一道回忆题。等题目到期时，练的是自己能否想出答案，而不是把整篇笔记重读一遍。

## 从你习惯的笔记方式开始

一篇笔记可以是一节课的总结、一道题的复盘、一个概念，或者一个还在慢慢理清的专题。你可以写标题、列表、表格、代码、公式，插入图片，也可以加一段简短的概览，方便以后迅速回到主题。阅读时不必一直面对编辑控件，需要修改时再切回编辑。

笔记会留在完整的笔记库中，可以搜索、排序、按标签浏览。你不需要先画一张地图，才能记下一件事。

笔记变长后，可以分成 **Section（小节）**。每个小节都是可以独立查找、调用和复习的知识单元，也就是 Nodal 所说的 **Node**；只是平时你更习惯在笔记里创建和编辑它。你可以给小节命名、移动或调整顺序、增加下级小节，或者切回连续的全文视图。每个小节可以有自己的题目、指导要求、复习计划和标签。如果另一篇笔记需要用到其中一节，可以插入实时引用：它显示原小节的最新内容，不必另存一份以后再逐处修改。

## 在不同情境里找到同一份知识

**Map（地图）**让你把已有笔记和小节放到画布上，用 Frame 分组，并画出它们之间的关系。同一篇笔记可以出现在多张地图里。从地图上移动或移除它，只改变那张地图的视角，不会删除原笔记；修改原文，各处看到的内容也会更新。

标签是另一条寻找知识的路径。标签可以分层，但不会把笔记锁在某个地方。贯穿全文的内容，可以给整篇笔记加标签；只涉及某一节的内容，就只标在那一节。例如，算法笔记整篇带有 **Algorithms**，只有实现代码的小节带有 **Java**。搜索 Java 仍能找到这篇笔记，却不会把其他小节也误认为 Java 内容。把竞赛笔记关联到 **Events** 中的比赛活动，其中的题目再按 **Math** 下的学科查找。只出现一次的技巧写在题解里即可，不必专门建标签。

## 检查自己能否想起，而不只是看着眼熟

挑一个值得记住的点，把它变成问题。问题仍连着来源，需要时可以回到完整解释，而不是只剩下一张孤立的卡片。对于已有解答的题，可以先只看题目，自己尝试求解，再翻卡揭示答案；也可以做选择题、填空题，或隐藏一段内容后尝试回忆。在 **Practice** 中，你可以集中查看一篇笔记的题目并选择练习；**Recall** 按到期时间整理题目；**Today** 帮你从今天要做的事开始。

在笔记的 **Practice** 中，用 **Add question** 或 **Edit** 直接新增、编辑题目与答案，使用和笔记相同的 Markdown 编辑器，支持公式、图片、表格和链接。题目直接按列表展示，Section 作为来源标签筛选、跳转；用 **Add source link** 可关联多个笔记中的 Section，也保留 JSON 导入。在 **Recall** 中点开的是这道题，揭示后查看答案；用 **View source** 打开原文，关闭原文即可回到题目。编辑保留题目 ID 和复习进度。

复习时先尝试回答，再揭示答案，按实际情况选择 **Forgot、Partial 或 Recalled**。结果会保存在这道题的记录里，并影响它下次出现的时间。不同题目各有自己的历史和安排，一篇笔记不必被当成一整块“会”或“不会”；尚未复习的内容也不会被显示成答错。

你还可以创建 **Review plan（复习计划）**，选择自适应、固定或自定义间隔，并按需要设置结束日期。计划可以安排给整篇笔记、某个小节或单道题；在 **Plan** 中回看已完成的复习和接下来的安排。这些工具帮助你形成节奏，但不会声称能预知考试成绩，或保证某个知识点已经完全掌握。

同一道题会显示在每篇关联笔记的 **All** 列表中；**Pending** 只保留尚未开始学习的题。所有关联 Note 和 Section 共用这道题的复习历史，参与各自的掌握度计算。

Heuer 竞赛题自动使用 **Heuer Contest Prep · Math** 计划，比赛日期取自 Events。每次评价后最早安排到下一个本地日期；记住的题逐步拉长间隔，临近比赛再检查一次，活动结束后停止备赛队列。分配计划保留已有历史，也不会自动开始尚未学习的题。

## 按自己的方式使用外部 AI

你可以给整篇笔记或某个小节保存 **Guidance（指导要求）**，例如“多问对比例子”或“检查边界情况”。导出时只选需要的小节，决定是否带上这些要求，还可以补一句仅用于这一次的说明。随后复制内容，或保存成 Markdown、含图片的 ZIP、可打印的文档。

如果想请外部 AI 帮你拟练习题，Nodal 可以提供出题提示词，并按支持的格式导入题目。由你选择工具、查看它的回答，再决定是否导入。**Nodal 不会自动把笔记发给 AI，也不会在应用里自行生成题目。**

## 把自己的内容保管好

[打开 Nodal](https://yajing5027.github.io/Nodal/)，从一篇笔记开始。当前网站把工作内容保存在你使用的浏览器中，没有账号或自动同步；公开站点与本地开发地址的数据也不会自动互通。请定期从 **Data & backup** 下载**完整备份**，尤其是在清理浏览器数据、更换浏览器或设备之前。导入备份会替换目标位置现有的工作区。

新建工作区时，你会看到两篇课程测验笔记及 Jerry Heuer 竞赛资料，并能尝试其中的练习题。所有这些内容都可以修改或删除。你自己写下的内容留在当前浏览器，除非主动导出。浏览器存储只是这个版本当前的实现方式，不代表 Nodal 将来只能在一台设备上使用。



## 从准备到开始学习

创建、导入或编辑练习不会自动开启复习。准备好学习某道题时，用 **Start learning** 主动开启；仅查看或揭晓答案不会保存成绩。已经开始学习的题，才会按照自己的复习时间进入 Today。

## 重要日期与学习进程

在 **Events** 中创建比赛、考试或每周 Quiz，设置日期或循环星期，关联相关笔记，自行开关首页显示和剩余天数。首页按临近日期排序，用简洁数字显示剩余天数。关联活动不会自动开始复习笔记中的题目。

**Study progress** 展示带更新时间的公开笔记、地图和逐题进度快照，与访客自己的工作区分开。正常备份保留成绩和复习安排，绝不清空进度；备份中的公开快照可用于更新网站，完整备份留作私人保存。

可选的 **Research recording** 独立保存内容修改、出题、揭晓和完成复习的记录，以及精确的复习时间和调度上下文。删除笔记或恢复旧备份后，已有研究记录仍然保留；原始回答和研究日志不进入公开进度快照。
